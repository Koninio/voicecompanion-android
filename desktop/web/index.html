설정

언어 모델 (LLM)

models 폴더의 GGUF 파일 중에서 골라요.
MoE CPU 오프로드: 비워두면 자동이에요. 모델 파일을 읽어 MoE(예: 26B)면 전문가를 RAM에 두고 나머지를 GPU에, 일반 모델(예: 12B)이면 남은 VRAM에 맞춰 자동 배치해요. 숫자를 넣으면 그 수만큼의 전문가 레이어만 RAM으로 보내요.
저장하면 모델이 다시 시작돼요 — 잠시 동안 LLM 상태가 '로딩 중'으로 표시돼요.

음성 합성 (TTS)

fish.audio → API Keys 에서 발급할 수 있어요.
fish.audio 보이스 페이지 URL 끝의 ID

음성 인식 (STT)

모델/장치 변경은 앱을 다시 시작하면 확실하게 적용돼요.
말을 멈춘 뒤 이 시간만큼 조용하면 대답을 시작해요.
